# `vibecoding/Logistics/Draw-Knockout.md`

淘汰赛级别与抽签来源。用户已批准对原文边界笔误的解释：所有正数包括 `1` 为种子，按级别降序确定种子号；`0` 为非种子小组第一，`-1` 为其余选手。种子批次为 3–4、5–8、9–16 等。

独立淘汰赛 CSV 可直接导入这三类级别；小于 `-1` 的级别无效。

种子签位采用 ITTF 按排名设种规则：一号种子在第 1 位，二号种子在第 `2^d` 位；第 `2^i+1` 到 `2^(i+1)` 号种子在奇数号 `1/2^i` 区底端与偶数号 `1/2^i` 区顶端之间随机抽签（64 签时 3–4 号在 32/33，5–8 号在 16/17/48/49），种子位置上下镜像对称。非种子小组第一随机进入没有种子的首轮场次，上半区占一号位、下半区占二号位。轮空每场至多一个，依种子号、再依非种子小组第一的抽签顺序放在其同场对面，剩余轮空放入随机的空场次。已抽签表不因规则更新而改变。其余人按小组名次从高到低随机占剩余位置，同组第 `k` 名避开同组已落位者所在的 `1/2^ceil(log2 k)` 区（第二名在另一半区），无解时逐级放宽。小签表使用能容纳的批次；同级别种子随机定序。

小组出线后，`n_s` 取原报名正种子人数与小组数的较小值；前 `n_s` 组第一按组号 `g` 得 `n_s + 1 - g`，其他第一得 `0`，其余出线者得 `-1`。数据库负责赋级别，纯逻辑负责分区抽签。
