# `tests/test_revision6_storage.py`

验证只填单侧 `wo` 时另一侧保存为零、单方和双方弃权的结束状态、输入校验、小组随机同分名次在重启及元数据编辑后的稳定性、排名撤销及恢复，以及新出线种子级别。

裁判测试覆盖小组计划覆盖所有场次、单场裁判不反向改变小组计划、重新抽签保留小组裁判。测试在独立临时数据库中运行。

独立淘汰赛名单测试覆盖单打、双打、团体 CSV 的正种子、`0`、`-1` 导入与数据库抽签；验证前两种子固定首尾签位、非种子第一进入无种子场次、人员完整及轮空数量。负数校验拒绝独立淘汰赛 `-2`、小组赛和循环赛 `-1`，失败不创建项目。

重启升级测试写入旧排名与种子结构，再初始化数据库：同一出线成员时更新种子且完整保留对阵比分；新排名改变资格成员时同步新名单并清空旧签表。共 8 项测试。

运行：`python -m unittest discover -s tests -p test_revision6_storage.py -v`。
