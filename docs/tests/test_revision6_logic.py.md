# `tests/test_revision6_logic.py`

验证 revision 6 的纯比赛逻辑，运行：

```powershell
D:\Anaconda3\envs\pkutta\python.exe -B -m unittest tests.test_revision6_logic -v
```

- 弃权：单方 `wo` 覆盖普通局多数，只填 `wo` 时另一方自动按零分处理，双方弃权无胜者；普通空分局忽略，非法比分拒绝。
- 淘汰赛：双方弃权向后传播轮空，双方轮空自动决出，最终结果不会因缺少胜者停住；单方弃权的负者仍可参加铜牌赛；裁判信息在重新计算对阵时保留。
- 小组排名：只有全组完赛才生成排名；按积分、并列者内部积分、精确局数比值、球分比值、持久化抽签排列排序；未涉及的比较字段为空，弃权按零计算比值。
- 淘汰赛抽签：头两种子固定首尾签位，3–4、5–8 等批次在 ITTF 规定签位并进入不同分区，非种子小组第一进入无种子场次且上下半区镜像，其余位置随机；检查种子 `1`、`0`、`-1`、小签表和输入不变性。
