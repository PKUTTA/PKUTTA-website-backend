# `README.md`

项目操作入口文档，说明环境与启动、唯一实时 JSON 数据库、CSV 规范、弃权录分、小组及独立循环赛共用的积分与比值排名、持久化排名抽签、淘汰赛 ITTF 种子签位、已抽签表不随规则更新而改变及出线级别、小组与循环赛时间桌号裁判的统一计划和单场安排、三表布局、手机居中和叶子编号。项目目录只用 `women-double` 等短名，浏览器地址使用 `#/xsb26/women-double` 等两级路径。旧独立循环赛胜场/局数/总分函数只保留给兼容调用，页面使用新规则。独立淘汰赛 CSV 接受 `-1`，启动升级按新小组排名同步旧出线元数据，同人选保留签表比分、换人选清空待重抽。三表共用 43px 表头和 46px 内容行，窄屏选手表固定 220px，宽矩阵与排名仅在各自容器内横向滚动。完赛结果卡片可折叠，表格至多 580px 并居中、姓名居中可查看详情；最终淘汰赛和循环赛前三名名次格分别黄、银、棕。项目第一阶段下提供默认收起的参赛名单，以可点击名字和逗号构成段落，下载 CSV 保留原报名列结构、顺序与种子级别，使用标准可再上传表头和 UTF-8 BOM。

创建赛事可选自定义文件名，输入始终显示且仅勾选后启用，重复名不覆盖。顶部品牌和 favicon 使用供应的 JPEG，固定顶栏预留内容高度；进入赛事后可以搜索各项目阶段中的成员相关场次。说明分块加载、60 秒内存缓存、并发去重、保存失效和旧请求保护，以及搜索部分失败保留已有结果。Submit 位于右下角，在 `webpage/` 仓库后台执行固定 Git 命令，输出终端，运行中禁用、失败弹窗、成功安静；发布无需构建。测试命令包括 Python 测试与六套 Node 前端检查。
